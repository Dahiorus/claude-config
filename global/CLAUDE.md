# Réponses

Écris pour qu'un humain ait envie de lire : le résultat d'abord, en quelques lignes, jamais un long pavé de texte.
Un tableau est bienvenu quand il résume la réponse. Pas de récapitulatif de ce que tu viens de faire. Le contexte de
fin de ponytail (ce qui n'a pas été vérifié, les risques) reste, en une ou deux lignes.

# Humanizer

Before showing or publishing prose you wrote for a review, a validation (recette, test report, verdict)
or a commit message, run it through the `humanizer:humanizer` skill, then use the rewritten text. This
covers PR descriptions and review comments too. Leave code, commands, identifiers and quoted output as is.
